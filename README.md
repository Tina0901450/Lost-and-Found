# 拾光 · 校园失物招领

单页 HTML 失物招领站点，打开 `index.html` 即可使用。

## 功能

- **我捡到了**：摄像头/相册上传，配置大模型后可识图提取物品描述，填写场所与联系方式后发布
- **我丢了东西**：浏览已发布的捡到物品（照片、地址、电话）
- **我发布的历史**：管理自己发的帖，点击「失主已找到」可删除

## 使用方式

1. 用浏览器打开项目里的 `index.html`
2. 进站后选择左右入口进入对应功能
3. 右上角「配置 AI」可填写视觉大模型 API（OpenAI 兼容接口）

## 说明

- 帖子数据保存在浏览器 `localStorage`，本机可见，未做多端同步
- API Key 仅保存在本机浏览器，不会上传到本仓库
- 部分云厂商接口可能因跨域（CORS）无法在浏览器直连，需自备兼容中转

## 部署（可选）

可推送到 GitHub，并在仓库 Settings → Pages 中开启 GitHub Pages，获得公开访问链接。
